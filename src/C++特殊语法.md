## 优化输入输出的语句

下面两句代码是C++中常用的优化输入输出的语句，特别在需要处理大量数据时。它们的作用如下：

### 1. `ios::sync_with_stdio(false);`

- **作用**：取消 C++ 标准 I/O 流（`cin`, `cout`）和 C 标准 I/O（`stdio`，如 `scanf`, `printf`）的同步。
- **详情**：
    - 默认情况下，`cin` 和 `stdio`（如 `scanf`）是同步的，为了保证两者在混合使用时数据的正确性。
    - 设置为 `false` 后，`cin` 和 `cout` 将不再与 `stdio` 相关联，从而去除同步开销，从而显示输入输出的速度会大幅提升。
- **注意事项**：取消同步后，不能同时使用 `scanf/printf` 和 `cin/cout`，否则可能导致输出乱序或其他意外。

### 2. `cin.tie(nullptr);`

- **作用**：解开`cin`和`cout`之间的自动绑定。
- **详情**：
    - 默认情况下，`cin` 会与 `cout` 绑定（`cin.tie(&cout)`），这意味着每次 `cin` 读操作前，都会自动刷新（flush）`cout`，确保输出和输入同步。
    - 绑定的好处是保证输出及时显示，避免在输入前输出被阻塞。
    - 设置为 `nullptr` 后，取消绑定，减少不必要的刷屏操作，提高读取速度，但需要注意在需要及时显示输出时，要手动调用 `cout.flush()` 或 `cout << endl`。

简单总结：

```cpp
ios::sync_with_stdio(false); // 提升读写速度，关闭同步
cin.tie(nullptr);            // 取消 cin 和 cout 自动绑定，减少开销
```

在竞赛或者大数据量输入输出场景下，使用这两句可以显著提升程序运行速度。
